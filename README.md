# Books-for-free
A collection of pdfs of different books that are part of the syllabus of different degree programs in FAST NUCES.

## Collaboration and Contributions
I welcome everyone and anyone viewing this repo to add to this collection. Please add the book(s) in the respective folder (subjectwise, e.g., ```./Data Structures```) in your own separate branch and raise a pull request afterwards. Naming scheme for pull request should be ```added <content> to <subject name>```
